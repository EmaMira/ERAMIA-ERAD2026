# Site VI ERAD | ERAMIA-NO2 2026 — Estilo Kubio SBC

Pacote completo contendo estrutura HTML, CSS adaptado do portal oficial da SBC (`sbc.org.br`) e identidade visual com os tons das logos oficiais (`#00FB00`, `#007D00`, `#003700`, `#000600`).

## Estrutura de Pastas
- `index.html`: Página principal completa pronta para abrir no navegador ou publicar no servidor da SBC (`/erad_eramia-no2/2026/`).
- `assets/css/sbc-erad-eramia.css`: Folha de estilos com os tokens `--kubio-color-*` e tipografia `Mulish` / `Syne` recoloridos.
- `assets/images/logo_ERAD-NO.png`: Logo oficial ERAD-NO2.
- `assets/images/logo_ERAMIA-NO.png`: Logo oficial ERAMIA-NO2.
- `assets/images/cartaz-artigos-aceitos-2026.jpg`: Cartaz de divulgação de artigos aceitos.
- `_includes/header.html` e `_includes/footer.html`: Componentes modulares para templates Jekyll / SBC.
- `pages/programa.html`: Tabela de programação no estilo TablePress SBC.
